**Quick Eat Mod** — это премиальный утилитарный мод для Minecraft 1.20.1 (Forge), который полностью избавляет игрока от рутины ручного питания. Ешьте еду мгновенно, прямо из инвентаря или даже открытых контейнеров, без необходимости выкладывать её на хотбар!

---

## 🎮 Главные фичи мода (Killer Features)

*   **⚡ Быстрое зажатие (Hold G to Eat):** Забудьте про кулдауны! Просто наведите курсор на еду в инвентаре и **зажмите клавишу G**. Первое поедание происходит мгновенно, а последующие — с оптимальной скоростью. Вы сможете съесть хоть целый стак на бегу за секунды!
*   **🤖 Умная авто-еда (Smart Auto-Eat):** Настраиваемый ИИ-помощник автоматически кормит вас при падении голода ниже заданного порога. Он сканирует ваш инвентарь, выбирает максимально подходящую еду по уровню насыщения (чтобы избежать «переедания» и потери ресурсов) и гарантированно обходит ядовитую еду (гнилую плоть, паучий глаз).
*   **🌟 Гастрономическое Комбо (Food Combo System):** Механика поощрения разнообразия питания. Если вы едите разную пищу подряд (например: *Яблоко ➡️ Стейк ➡️ Печенье*), то накапливаете комбо-очки и получаете мощные положительные баффы (Регенерация, Скорость, Сила). Повторное поедание одного и того же блюда сбрасывает комбо!
*   **🎨 Премиальные HUD-тосты (Custom UI Toast Notifications):** Никакого спама в чат! Мод содержит полностью кастомную систему всплывающих уведомлений в углу экрана. При поедании плавно появляется красивое меню с 3D-иконкой еды, её названием и количеством восполненного голода. Позицию уведомлений (любой из 4 углов) можно настроить.
*   **🎒 Универсальная совместимость (Out-of-the-Box Compatibility):** Мод автоматически считывает характеристики любой еды из сторонних модов (включая напитки и жажду из *Legendary Survival Overhaul* и кулинарию из *Farmer's Delight*). Кроме того, вы можете есть прямо из открытых сундуков, бочек, рюкзаков или шалкеров!

## ⚙️ Управление и Настройки

### ⌨️ Горячие клавиши
*   **`G` (по умолчанию)** — Наведите курсор на еду в инвентаре и нажмите/зажмите для быстрого поедания.
*   *Переназначение:* Клавишу можно переназначить в стандартном меню игры: `Настройки ➡️ Управление ➡️ раздел "Быстрая еда"`.

### 🛠️ Настройки мода (Без сторонних библиотек!)
Вам **НЕ нужно** скачивать тяжелые сторонние библиотеки вроде *Cloth Config*. Настройки встроены прямо в игру через ванильный интерфейс и доступны через кнопку настроек мода в списке модов Forge.

Настройки разделены на три удобные вкладки:
1.  **Общие (General):** Включение звуков, частиц при поедании, отображения всплывающих подсказок на еде, запрет поедания сытым, а также выбор угла экрана для уведомлений (`BOTTOM_RIGHT`, `BOTTOM_LEFT`, `TOP_RIGHT`, `TOP_LEFT`).
2.  **Авто-еда (Auto-Eat):** Включение авто-поедания и ползунок порога сытости (например, срабатывать, когда сытость падает ниже 7 окорочков).
3.  **Комбо-система (Combo System):** Включение комбо, настройка времени сброса и минимального количества блюд для получения эффектов.

#### Файлы конфигурации на диске:
Все параметры автоматически сохраняются и могут быть отредактированы вручную:
*   Клиентские настройки: `.minecraft/config/quickeat-client.toml`
*   Настройки сервера/мира: `.minecraft/config/quickeat-common.toml`

## 📥 Установка

> ⚠️ **ВАЖНО:** Этот мод разработан строго под **Minecraft Forge** версии **1.20.1**. Он **НЕ будет** работать на загрузчиках Fabric, Quilt или NeoForge. Попытка установить его туда приведет к крашу игры.

1.  Убедитесь, что у вас установлена правильная версия **Minecraft 1.20.1** и **Forge** (рекомендуется версия `47.2.0` или выше).
2.  Скачайте последнюю версию мода `quickeat-1.2.0.jar` со [страницы релизов](https://github.com/fagred35-dot/QuickEatMod/releases).
3.  Переместите скачанный файл в папку `.minecraft/mods/`.
4.  Запустите игру через лаунчер с профилем Forge.

## 🛠️ Сборка из исходников

Если вы хотите самостоятельно скомпилировать мод из исходного кода:

### Требования:
*   Установленная JDK версии 17 или 21.

### Процесс сборки:
1.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/fagred35-dot/QuickEatMod.git
    cd QuickEatMod/"мод на авто поедание"
    ```
2.  Запустите скрипт сборки:
    *   **Windows (PowerShell/CMD):**
        ```cmd
        # Если в пути пользователя есть кириллица, обязательно перенаправьте Gradle кэш:
        $env:GRADLE_USER_HOME="C:\gradle_home"
        .\gradlew.bat build
        ```
    *   **Linux / macOS:**
        ```bash
        chmod +x gradlew
        ./gradlew build
        ```
3.  Заберите готовый файл мода по пути: `build/libs/quickeat-1.2.0.jar`.

## 📌 Известные особенности и совместимость

*   **Моды на авто-поедание:** Настоятельно рекомендуется отключить встроенное авто-поедание в других утилитах или модах (например, в некоторых чит-клиентах или крупных модах на интерфейс), чтобы избежать двойного расхода еды.
*   **Сетевой код:** Мод полностью адаптирован под мультиплеер. Серверная часть содержит надежную валидацию пакетов (античит), не позволяя игрокам сымитировать поедание несуществующей еды.
*   **Локализация:** Полная поддержка русского (`ru_ru`) и английского (`en_us`) языков для интерфейса настроек, уведомлений и подсказок.
