# Quick Eat Mod (Minecraft 1.20.1 Forge)

## Что делает мод
Позволяет есть еду прямо из инвентаря без переноса на панель быстрого доступа.

**Как использовать:** Открой инвентарь → Наведи курсор на еду → Нажми **G**

## Совместимость
- Вся ванильная еда (гнилая плоть, паучий глаз, золотые яблоки и т.д.)
- Любая модовая еда (автоматически определяется)
- Напитки и предметы жажды из **Legendary Survival Overhaul**
- Зелья и любые предметы с анимацией еды/питья

## Как собрать

### Требования
- Java 17 или выше (у тебя Java 21 — подходит)
- Интернет (для первой сборки Gradle скачает ~500MB зависимостей)

### Сборка
1. Дважды кликни `BUILD.bat`
2. Или в командной строке:
   ```
   set GRADLE_USER_HOME=C:\gradle_home
   gradlew.bat build
   ```
3. Готовый мод: `build\libs\quickeat-1.0.0.jar`

### Важно
- `GRADLE_USER_HOME=C:\gradle_home` нужен из-за кириллицы в пути пользователя
- Первая сборка занимает 5-10 минут (скачивание Minecraft + Forge)
- Если сборка падает с timeout — просто запусти ещё раз

## Установка
Скопируй `quickeat-1.0.0.jar` в папку `.minecraft/mods/`

## Настройки
Клавишу G можно переназначить в: Настройки → Управление → категория "Быстрая еда"
