**Quick Eat Mod** — это премиальный умный макрос для Minecraft 1.20.1 (Forge), который избавляет игрока от рутины ручного питания. Мод интеллектуально сканирует инвентарь, выбирает лучшую еду или напитки, берет их в руку и автоматически съедает с ванильной анимацией. Работает 100% легально для серверов (не нарушает античиты)!

---

## 🎮 Главные фичи мода (Killer Features)

*   **🤖 Умная авто-еда (Smart Auto-Eat):** ИИ-помощник автоматически кормит вас при падении голода ниже заданного порога. Включается и выключается одной кнопкой `H` прямо во время игры с красивым уведомлением на экране!
*   **🧠 Интеллектуальный выбор еды (Food Evaluator):** 
    *   **Режим Идеал:** Ищет еду, которая максимально точно восполнит текущий голод без перерасхода (бережет топовые стейки, если вам нужна всего одна "ножка").
    *   **Режим Паника:** Если у вас осталось 3 сердечка (6 ХП) или меньше, мод переходит в экстренный режим и будет есть самую сытную еду или Золотые Яблоки, игнорируя перерасход!
*   **☠️ Защита от отравлений и Блэклист:** Мод автоматически сканирует еду на предмет негативных эффектов (Яд, Голод, Урон) и отказывается её есть. Также в меню есть встроенный графический **Блэклист**, куда можно вписать любую еду, которую вы хотите запретить моду трогать (например, яблоки для крафтов).
*   **🕹️ "Легальный" Макрос (ZynAutoEat Style):** При поедании мод мгновенно меняет ваш текущий предмет (например, меч) на еду, зажимает ПКМ, ждет окончания ванильной анимации, и затем идеально **возвращает старый предмет и слот** на место. Никаких серверных десинков и конфликтов с античитами!
*   **⚡ Умные прерывания:** Если во время процесса авто-поедания вы получаете урон или сами нажимаете ЛКМ/ПКМ (чтобы атаковать или строить), мод мгновенно прерывает поедание и отдает вам управление.
*   **🥤 Поддержка напитков:** Мод сканирует анимации предметов и отлично пьет зелья, воду и кастомные напитки из других модов!

## ⚙️ Управление и Настройки

### ⌨️ Горячие клавиши
*   **`H` (Toggle Auto-Eat)** — Включить / Выключить режим авто-поедания в реальном времени.
*   **`G` (Eat Until Saturated)** — Нажмите в игре, и мод будет автоматически перебирать еду и есть её до тех пор, пока полоска голода не заполнится на 100%.

### 🛠️ Настройки мода (Без сторонних библиотек!)
Вам **НЕ нужно** скачивать сторонние библиотеки вроде *Cloth Config*. Настройки встроены прямо в игру через ванильный интерфейс и доступны через кнопку настроек мода в списке модов Forge.

Настройки разделены на 4 удобные вкладки:
1.  **Общие (General):** Включение звуков, частиц при поедании, отображения подсказок и т.д.
2.  **Авто-еда (Auto-Eat):** Включение авто-поедания и ползунок порога сытости (например, срабатывать, когда сытость падает ниже 7 окорочков).
3.  **Комбо-система (Combo System):** Настройка бонусов за разнообразное питание.
4.  **Блэклист (Blacklist):** Окно для ввода ID предметов через запятую, которые мод никогда не должен есть.

## 📥 Установка

> ⚠️ **ВАЖНО:** Этот мод разработан строго под **Minecraft Forge** версии **1.20.1**. Он **НЕ будет** работать на загрузчиках Fabric или NeoForge.

1.  Убедитесь, что у вас установлена правильная версия **Minecraft 1.20.1** и **Forge** (рекомендуется версия `47.2.0` или выше).
2.  Скачайте последнюю версию мода `quickeat-1.3.0.jar` со [страницы релизов](https://github.com/fagred35-dot/QuickEatMod/releases).
3.  Переместите скачанный файл в папку `.minecraft/mods/`.
4.  Запустите игру через лаунчер с профилем Forge.

---

## 🛠️ Сборка из исходников

Если вы хотите самостоятельно скомпилировать мод из исходного кода:

1.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/fagred35-dot/QuickEatMod.git
    cd QuickEatMod/"мод на авто поедание"
    ```
2.  Запустите скрипт сборки:
    *   **Windows (PowerShell/CMD):**
        ```cmd
        # Если в пути пользователя есть кириллица, обязательно перенаправьте Gradle кэш:
        $env:GRADLE_USER_HOME="C:\gradle_home"
        .\gradlew.bat build
        ```
    *   **Linux / macOS:**
        ```bash
        chmod +x gradlew
        ./gradlew build
        ```
3.  Заберите готовый файл мода по пути: `build/libs/quickeat-1.3.0.jar`.
