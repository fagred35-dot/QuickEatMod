# Quick Eat Mod (Minecraft 1.20.1 Forge)

## Что делает мод
Позволяет есть еду прямо из инвентаря без переноса на панель быстрого доступа.

**Как использовать:** Открой инвентарь → Наведи курсор на еду → Нажми **G**

## Совместимость
- Вся ванильная еда (гнилая плоть, паучий глаз, золотые яблоки и т.д.)
- Любая модовая еда (автоматически определяется)
- Напитки и предметы жажды из **Legendary Survival Overhaul**
- Зелья и любые предметы с анимацией еды/питья

## Установка
Скачай `quickeat-1.2.0.jar` из раздела Releases и скопируй в папку `.minecraft/mods/`

## Настройки
Клавишу G можно переназначить в: Настройки → Управление → категория "Быстрая еда"
