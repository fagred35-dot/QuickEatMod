## 🎮 Геймплей (1-25)

1. **Частицы еды** — показывать частицы при поедании как в ванилле
2. **Анимация руки** — короткая анимация поднесения еды ко рту
3. **Очередь поедания** — зажать G чтобы есть подряд несколько штук
4. **Авто-еда** — автоматически есть когда голод ниже порога
5. **Приоритет еды** — авто-еда сначала ест худшую еду, потом лучшую
6. **Быстрое питьё зелий** — пить зелья из инвентаря тем же способом
7. **Поедание стаком** — съесть N штук за раз (настраиваемое количество)
8. **Индикатор насыщения** — показывать сколько голода/насыщения даст еда
9. **Запрет поедания при полном голоде** — не тратить еду зря (настраиваемо)
10. **Поедание в бою** — разрешить/запретить быстрое поедание во время боя
11. **Бросок еды** — кинуть еду другому игроку по клавише (мультиплеер)
12. **Кормление питомцев** — быстро покормить волка/кота из инвентаря
13. **Кормление деревенских жителей** — быстро дать еду жителю
14. **Компостирование** — быстро кинуть еду в компостер
15. **Поедание с земли** — подобрать и сразу съесть еду с земли
16. **Разделение стака** — съесть только 1 штуку из стака (уже работает)
17. **Быстрое использование** — расширить на любые "используемые" предметы (щиты, луки)
18. **Поедание во время бега** — не останавливаться при быстром поедании
19. **Комбо-еда** — бонус за поедание разной еды подряд
20. **Рецепт в тултипе** — показать из чего сделана еда
21. **Калории** — показать общую "ценность" еды (голод + насыщение)
22. **Сравнение еды** — при наведении показать что лучше текущей
23. **Избранная еда** — пометить еду как "любимую" для авто-еды
24. **Запрет определённой еды** — чёрный список (не есть гнилую плоть автоматически)
25. **Горячая клавиша "съесть лучшее"** — автоматически найти и съесть лучшую еду в инвентаре

## ⚙️ Конфигурация (46-60)

46. **Серверный конфиг** — админ может отключить мод на сервере
47. **Per-player настройки** — каждый игрок настраивает под себя
48. **Профили настроек** — быстрое переключение между пресетами
49. **Белый список предметов** — только определённые предметы можно быстро есть
50. **Чёрный список предметов** — запретить быстрое поедание определённых
51. **Настройка звука** — громкость, вкл/выкл для каждого типа
52. **Настройка тултипа** — позиция, цвет, формат текста
53. **Горячая клавиша вкл/выкл мод** — быстро отключить без захода в настройки
54. **Конфиг через GUI** — красивое меню настроек (Cloth Config / ModMenu)
55. **Импорт/экспорт конфига** — поделиться настройками с друзьями
56. **Настройка кулдауна per-item** — разный кулдаун для разной еды
57. **Режим "только голод"** — есть только когда голоден
58. **Режим "всегда"** — есть даже при полном голоде (для эффектов)
59. **Лимит поедания в минуту** — антиспам защита для серверов
60. **Настройка модификатора** — Shift+G, Ctrl+G и т.д.
